# Local property inbox

Drop each property's folder, documents, images, ZIP, and video links here, or give the agent their existing local path. Write "Add this property to Following Sky" in the project chat. Existing filenames are fine.

The agent reads the sources, organises the listing, and saves its working notes in the property's `brief.md`. You do not need to fill in a form.

Everything in this directory except this README is ignored by Git. Originals and briefs stay on this computer. The agent copies selected public assets into the website's image folders. A fresh checkout will need the original materials supplied separately.

See [START-HERE.md](../START-HERE.md) and [PROPERTY-WORKFLOW.md](../PROPERTY-WORKFLOW.md).
