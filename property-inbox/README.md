# Local property inbox

Drop each property's folder, documents, images, ZIP, and video links here, or give the agent their existing local path. You can also paste a client property link directly in chat, along with any vertical YouTube Short or horizontal tour links. Write "Add this property to Following Sky" in the project chat. Existing filenames are fine.

The agent reads the sources, obtains accessible property photos, organises the listing, and saves its working notes and source links in the property's `brief.md`. It asks for additional files or screenshots only when particular material cannot be obtained. You do not need to fill in a form.

Everything in this directory except this README is ignored by Git. Originals and briefs stay on this computer. The agent copies selected public assets into the website's image folders. A fresh checkout will need the original materials supplied separately.

See [START-HERE.md](../START-HERE.md) and [PROPERTY-WORKFLOW.md](../PROPERTY-WORKFLOW.md).
